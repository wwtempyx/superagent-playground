# Contributing

## Setup

1. Clone the repository:

   ```
   git clone https://github.com/wwtempyx/superagent-playground.git
   cd superagent-playground
   ```

2. Install: this repository has no dependencies, so there is nothing to install.

3. Run: there is no local application yet; CI runs on GitHub Actions via `.github/workflows/`.

## Pull requests

Open a pull request against `main` describing your change.
